# GestaoDoProjetos
Este é um exercicio para a Master D. O Objetivo é desenvover um MPV de um waeapp de gestão de projetos em TypeScript

Rodar o sistema

1. Instalar o noje
2. Instalar o JSON server
    2.1. Abrir o terminal
    2.2. npm install -g json-server
3. Iniciar o JSON server
    3.1. npx json-server --watch data/content.json
4. instalar o live server dentro do SVCode
